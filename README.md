# Кінопанель — Практична робота № 6
**Тема:** База даних і вебзастосунок  
Це навчальний застосунок на Python, SQLite і Streamlit. 
## Що вміє кінопанель
- Фільтрує фільми за роками випуску й режисерами.
- Показує частку фільмів із тегами, графік накопичених глядачів і гістограму.
- Додає теги до вибраного фільму через форму.
